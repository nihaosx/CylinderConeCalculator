# 🎓 圆柱圆锥计算器 — 数学课堂演示工具

&gt; 不只是计算器，更是你的几何教学助手

## 为什么做这个？

初中数学课上，学生总是分不清：
- 直径和半径怎么换算？
- 圆锥体积为什么是圆柱的 1/3？
- 已知周长怎么求半径？

这个工具把**计算过程**和**图形演示**结合起来，让几何体积计算一目了然。

## 核心功能

| 功能 | 课堂价值 |
|------|---------|
| 🎨 **实时画图** | 投影到黑板，学生看到立体图形 |
| 📝 **分步展示** | 不是直接给答案，展示每一步怎么算 |
| 📄 **导出作业** | 一键生成标准解题格式，学生照抄 |
