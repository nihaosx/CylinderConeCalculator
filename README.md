# 🎓 圆柱圆锥计算器 — 数学课堂演示工具

> 不只是计算器，更是你的几何教学助手

一个专为 **初中数学教育** 设计的圆柱/圆锥体积计算工具，支持 **实时图形绘制** 和 **分步解题展示**，让几何体积计算一目了然。

A cylinder & cone calculator designed for **math education**, featuring real-time graphics and step-by-step solutions.

---

## 🎯 为什么做这个？

初中数学课上，学生总是分不清：

- 直径和半径怎么换算？
- 圆锥体积为什么是圆柱的 1/3？
- 已知周长怎么求半径？

这个工具把 **计算过程** 和 **图形演示** 结合起来，让抽象的公式变成看得见、摸得着的图形。

---

## ✨ 核心功能

| 功能 | 课堂价值 | 学生价值 |
|:---|:---|:---|
| 🎨 **实时 2D/3D 图形** | 投影到黑板，学生看到立体图形 | 直观理解 r 和 h 的位置 |
| 📝 **分步展示** | 不是直接给答案，展示每一步推导 | 对照步骤，学会解题思路 |
| 📄 **导出作业** | 一键生成标准解题格式 | 直接抄写到作业本 |
| 🔄 **多种输入** | 半径 / 直径 / 周长 三种方式 | 无论题目给什么条件都能算 |
| 🔢 **自定义 π** | 标准 π 或手动输入 | 满足不同精度要求 |
| 🌐 **中英双语** | 一键切换界面语言 | 适应不同教学环境 |

## 📖 使用说明

### 老师上课用
1. 选择输入方式（半径 / 直径 / 周长）
2. 输入题目给的数值和高
3. 勾选 **分步模式**
4. 点击 **计算**
5. **投影到黑板**：左边是解题步骤，右边是立体图形
6. 学生跟着步骤理解公式推导

### 学生做作业用
1. 输入自己的题目数据
2. 点击 **计算** 看结果
3. 对照 **分步过程** 检查自己的解题步骤
4. 点击 **保存作业**，生成 `homework.txt`
5. 打开文件，直接抄写到作业本

## 🛠️ 技术栈

| 技术 | 用途 |
|:---|:---|
| C++17 | 核心计算逻辑 |
| Win32 API | 原生 GUI 界面 |
| OpenGL + GLU | 3D 图形渲染 |
| GDI/GDI+ | 2D 几何图形绘制 |

### 自行编译

```bash
# 使用 MinGW-w64
g++ -o CylinderConeCalculator_v4.2.exe cylinder_cone_v4.2.cpp \
    -lopengl32 -lglu32 -lgdi32 -lcomctl32 -mwindows -static-libgcc -static-libstdc++
```
